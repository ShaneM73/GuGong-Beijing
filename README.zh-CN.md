# GuGong-Beijing · 北京中轴线三维模型

[English](README.md) · **中文**

故宫（紫禁城）与整条北京中轴线的交互式三维模型，南起永定门，北至钟楼（全长约 7.8 公里），用 three.js 按 1:1 米制构建。

**[打开模型](https://shanem73.github.io/GuGong-Beijing/?lang=zh)**

## 模型内容

“北京中轴线”世界遗产的全部 15 处构成要素均已建模，由南向北依次为：

- 永定门、中轴线南段道路遗存与天桥
- 天坛：祈年殿、丹陛桥、皇穹宇与回音壁、圜丘、斋宫
- 先农坛：太岁殿、先农神坛、观耕台、神仓、庆成宫
- 正阳门城楼与箭楼
- 天安门广场：人民英雄纪念碑、毛主席纪念堂、人民大会堂、中国国家博物馆
- 外金水桥、天安门、端门
- 太庙与社稷坛
- 故宫：城墙、护城河、午门、四座角楼、三台上的三大殿、后三宫、东西六宫、御花园、宁寿宫区、慈宁宫区等
- 景山、地安门雁翅楼、万宁桥、鼓楼与钟楼

## 使用方法

- 拖动旋转，双指或滚轮缩放，点按建筑可查看名称、尺寸、简史与估算经纬度。
- 底部导览条由南向北排列，点按即可飞到对应地标。
- 带金色圆点的建筑可以“入殿参观”，如太和殿、乾清宫、养心殿、祈年殿、鼓楼等。殿内有柱网、宝座、屏风、匾额与天花。
- “剖顶”隐藏全部屋顶，可从上方俯视殿内；“标签”“阴影”分别开关建筑名称与日照阴影；“全轴”“故宫”在整条中轴线与紫禁城之间切换。

界面默认为英文，可用标题下方的按钮切换为中文、日本語或한국어；所选语言会记在当前设备上，也可在网址后加 `?lang=zh`（或 `ja`、`ko`、`en`）直接打开对应语言。建筑名称、类别、尺寸与介绍均已翻译；殿内匾额保留原有汉字。

## 精度说明

- 已核对公开数据：宫城平面（961 m × 753 m）、护城河宽（52 m）、城墙高（10 m）、午门城台（12 m）、三台（8.13 m）、角楼（27.5 m）；中轴线全长（7.8 km）及 15 处构成要素；天安门广场（762 m × 280 m）；祈年殿及其坛台；丹陛桥与回音壁。
- 采用常见公开数据、未逐项核对：故宫主要殿宇、各城门楼、鼓楼与钟楼、纪念碑的尺寸；轴线方位（北端偏西约 2°）；中心点坐标。
- 近似处理：建筑沿轴线的位置按典型间距排布，并非测绘坐标，误差可能有几十米；天坛、先农坛离轴线的东西距离误差可能更大。次要院落的位置为近似。
- 仅作示意：灰色城市街区、轴线西侧的湖面、北海白塔、斗拱与彩画（以贴图表现），以及广场上 1950 年代建筑的体量。

## 构建

`index.html` 是构建好的独立页面，可直接打开，或从仓库根目录启动静态服务。

```bash
npm install
npm run build   # 把 src/ 打包进 index.html
```

- `src/model.js`：生成全部几何体与可点选建筑列表。
- `src/main.js`：查看器，包括相机、点选、标签、入殿模式与界面。
- `src/i18n.js`：英文、日文、韩文翻译（中文原文在 `src/model.js` 中）及四种语言的界面文字。
- `template.html`：页面结构与样式。

three.js r160 从 jsDelivr 加载；标题字体为 Google Fonts 的 Noto Serif SC、JP、KR（JP 与 KR 仅在选用时加载）。
